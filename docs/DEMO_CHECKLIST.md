# Final Demo Checklist

1. Login/logout with at least requester, technician and manager accounts.
2. Requester creates a ticket with an attachment.
3. AI suggestion displays category, priority, confidence and suggested KB/steps.
4. Manager assigns the ticket.
5. Technician changes Open -> In Progress -> Resolved and provides a resolution note.
6. Requester sees public comments but not internal notes.
7. Notification appears after ticket changes.
8. SLA countdown/breach information is visible.
9. Search finds a ticket and a KB solution.
10. Manager dashboard shows ticket/SLA metrics and exports CSV.
11. Health endpoint returns OK.
12. Operations dashboard shows response time/error metrics.
13. Run a backup and restore it to an isolated database.
14. Run the CI pipeline once successfully.
15. Demonstrate a failing test blocking deployment.
16. Build and deploy the container to staging.
17. Demonstrate application rollback to the previous image tag.
18. Demonstrate the health alert script with the service stopped.
19. Explain AI fallback behavior when the AI suggestion path fails.
20. Explain each team member's code ownership and Git/PR evidence.
